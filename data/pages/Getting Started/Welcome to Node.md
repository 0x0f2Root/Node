# Welcome to Node

Node is a Markdown‑first workspace for writing, organizing and navigating your
notes — with a few practical tools built in. Your pages are plain `.md` files
on disk, so they stay portable and easy to back up.

This short guide introduces the main areas. Open the pages in the **Getting
Started** workspace on the left, or create your own and delete these whenever
you like.

## What you get

- **A real editor** — write in a Visual editor or switch to an MDX source view
  with line numbers and syntax highlighting. Changes autosave.
- **A workspace tree** — group pages into workspaces and folders, star
  favorites, and tag pages by topic.
- **Fast navigation** — full‑text search and a command palette (`Ctrl`/`⌘ K`).
- **Tasks & Calendar** — a drag‑and‑drop board and a calendar, kept in your
  browser.
- **Developer tools** — a data encoder/decoder and a reverse‑shell generator
  for technical and security work.

## Your notes are files

Every page is a Markdown file under `data/pages/` in the project. Folders are
real directories, and the file name is the page title. You can edit these files
in any other editor, keep them in version control, or copy the folder to back
them up.

> Tip: press `Ctrl`/`⌘ K` anywhere to jump to a page or run a command.
