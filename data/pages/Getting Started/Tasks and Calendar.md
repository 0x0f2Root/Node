# Tasks and Calendar

Beyond notes, Node has a simple task board and a calendar to track your work.

## Tasks

The **Tasks** page is a Kanban board grouped by status — **To Do**, **In
Progress** and **Done**. Drag a card between columns to change its status.

- Create a task with **New task**; give it a title, description, priority, due
  date and an optional **linked page**.
- The filter bar narrows the board by **priority**, **status** and **due** date.

## Calendar

The **Calendar** page shows your events across month, week and day views.
Create an event with **New event** — set a date and time (or mark it **all
day**), pick a color, and optionally link it to a page. Drag an event to
reschedule it.

Tasks with a due date also appear on the calendar on that day, so you can see
notes, tasks and events in one place.

## Where this data lives

Tasks and events are stored **in your browser** (local storage), not in the
project files. They are per‑device and are not shared or committed to Git. See
**Backing up your data** in the project README.
